DEVELOPMENT RULES

이 문서는 프로젝트를 진행하면서 추가되는 Notebook 작성 규칙, 코딩 규칙, 검증 규칙을 한곳에 모아 관리합니다.

1. Notebook 기본 작업 단위

모든 Notebook 작업은 아래 3단계를 하나의 세트로 진행합니다.

1) 작업 계획 — Markdown Cell
이번 셀에서 무엇을 할지 작성
왜 이 작업이 필요한지 간단히 작성
확인할 항목을 명확히 작성
2) 실제 코드 — Code Cell
현재 작업에 필요한 코드만 작성
초보자가 이해할 수 있도록 간단한 주석 사용
한 번에 너무 많은 작업을 넣지 않음
3) 실행 결과 해석 / 분석 / 요약 — Markdown Cell
실행 결과가 무엇을 의미하는지 작성
예상과 다른 부분이 있는지 확인
다음 단계로 넘어가도 되는지 판단
필요하면 추가 확인 사항 기록

기본 패턴:

작업 계획 (Markdown)
↓
실제 코드 (Code)
↓
실행 결과 해석 / 분석 / 요약 (Markdown)
2. 규칙 추가 원칙

앞으로 새로운 코딩 규칙이나 작업 원칙이 생기면 이 문서에 계속 추가합니다.
